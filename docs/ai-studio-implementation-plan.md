# Preset 1 浅色模式局部提亮与瓷白层次优化方案

在保留整体**纯正中性石膏银灰（Neutral Stone-Silver `#e2e2e2 → #d5d5d5 → #c4c4c4`）**底色的前提下，将框选的四大核心区域（主画布卡片、顶部任务标签页、侧边栏新建会话按钮、侧边栏选中会话行）提亮提白为**温润白瓷渐变（`#fafafa → #efefef`）**，并同步微调主画布内部的输入控制台与工作区选择胶囊，使各层级与底色形成干净、通透且不过度突兀的明度阶梯。

## 用户确认与关键决策

> [!IMPORTANT]
> 以下视觉参数已根据您的选择完成锁定，将在批准后精确应用至选定组件与关联层级：

- **确认决策 1（框选区域提亮幅度）**：采用**纯白瓷感渐变（`#fafafa` 至 `#efefef`）**对框选的 4 个核心区域进行提亮提白，使其与 `#d5d5d5 / #dadada` 石膏银灰底色拉开清晰但克制的明度差，呈现轻薄悬浮感。
- **确认决策 2（主画布内部组件同步微调）**：主画布卡片提亮后，其内部的**底部输入控制台**与**工作区/模式选择胶囊**同步再提亮半级（`#ffffff` 至 `#f5f5f5` 柔白微光），确保内部控件在提亮后的主画布上依然具备清晰的悬浮层次。

---

## 1. 整体概览与核心目标

- **改进内容**：针对您框选的 4 处界面组件（主工作区画布、顶部标签页、新建会话按钮、当前选中会话项）及其内部输入交互区，建立三层中性无色偏（`R = G = B`）的明度递进体系。
- **适用场景**：Preset 1（Apple Liquid Glass / 哑光石膏白瓷浅色模式）下的日常会话、多任务标签切换与工作区指令输入。
- **核心价值**：解决此前浅色模式下组件与背景灰阶过于接近、视觉边界偏灰暗的问题；通过“石膏灰底 → 柔白瓷主卡/按钮 → 纯白微光输入台”的自然明度差，兼顾轻薄质感与清晰的视觉聚焦。

---

## 2. 视觉设计与明度层次（Visual Identity & Luminance Hierarchy）

- **三阶中性明度体系（Zero-Blue Neutral Luminance Scale）**：
  - **第一阶：底层画布与侧栏底色（Canvas & Sidebar Base）**
    - 保持参考图同款中性石膏灰底色（外层环境背景 `#e2e2e2 → #d5d5d5 → #c4c4c4`，左侧边栏半透明磨砂底 `rgba(220, 220, 220, 0.78)`），作为稳重的衬底。
  - **第二阶：框选的四大核心组件（Lifted Alabaster-Porcelain Surfaces）**
    - **主画布卡片（CSS Selector 1）**：由原本偏灰的 `#d7d7d7` 提亮至 **`#efefef → #e5e5e5` 柔白瓷渐变**（主色 `#eaeaea`），顶部配 `rgba(255, 255, 255, 0.88)` 高光切边，右侧与底部配柔和阴影。
    - **侧边栏选中会话行（CSS Selector 2）**：提亮为 **`linear-gradient(180deg, #f8f8f8 0%, #ededed 100%)`**，内嵌 `rgba(255, 255, 255, 0.92)` 顶边高光与 `rgba(0, 0, 0, 0.065)` 细腻外轮廓，在侧边栏灰底上温和浮起。
    - **侧边栏“New Session”按钮（CSS Selector 3）**：提亮为 **`linear-gradient(180deg, #fafafa 0%, #efefef 100%)`**，悬停时升至 `#ffffff → #f4f4f4`，配轻薄底阴影与白瓷顶边。
    - **顶部任务标签页与新建标签按钮（CSS Selector 4）**：当前激活标签与 `+` 按钮提亮为 **`linear-gradient(180deg, #fafafa 0%, #efefef 100%)`**，非激活标签采用半透明柔白 `rgba(244, 244, 244, 0.86)`，与顶部石膏灰背景自然区分。
  - **第三阶：主画布内部悬浮控件（Inner Elevated Controls）**
    - **工作区与模式选择胶囊**：比主画布再亮半级，采用 **`linear-gradient(180deg, #ffffff 0%, #f4f4f4 100%)`**，搭配 `rgba(0, 0, 0, 0.07)` 纤细轮廓与微弱环境阴影。
    - **底部输入控制台与附件按钮**：采用 **`linear-gradient(180deg, #ffffff 0%, #f5f5f5 100%)`** 纯净白瓷卡片表面，配 `inset 0 1px 0 #ffffff` 顶部亮边与柔和漫反射阴影。

## 3. 关键设计决策与权衡

- **决策 1：主画布（`#efefef → #e5e5e5`）与按钮/标签（`#fafafa → #efefef`）的微差控制**
  - *采用方案*：大面积的主画布卡片提亮至柔白 `#efefef → #e5e5e5`，而小面积的按钮、选中会话行与顶部标签提亮至 `#fafafa → #efefef`，主画布内部的输入框则升至 `#ffffff → #f5f5f5`。
  - *原因*：若大面积主画布直接设为刺眼纯白 `#ffffff`，不仅会破坏参考图右上角凹槽与石膏背景的立体衔接，也会导致画布内部的输入框无法再向上提亮。采用半级递进既能让主画布与 `#d5d5d5` 底色明显区分，又能保留参考图的石膏白瓷高级感。
- **决策 2：保持零色偏（`R = G = B`）与柔和阴影边界**
  - *采用方案*：所有提亮后的亮白渐变严格保持 `R = G = B` 纯中性色值，边框维持 `rgba(0, 0, 0, 0.065 ~ 0.09)` 极细灰阶轮廓。
  - *原因*：避免混入冷蓝或暖黄杂色，确保与右上角胶囊滑块和石膏底色浑然一体。

## 4. 技术架构与视觉层级映射

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 底层画布 (Studio Base: #e2e2e2 → #d5d5d5 → #c4c4c4 中性石膏灰)             │
├──────────────────────────────┬────────────────────────────────────────────┤
│ 左侧边栏 (rgba(220,220,220)) │ 顶部栏 (透明衬底)                            │
│  ├─ [Selector 3] 新建会话按钮 │  └─ [Selector 4] 任务标签页 & '+' 按钮       │
│  │   (#fafafa → #efefef)     │      (激活: #fafafa → #efefef)              │
│  └─ [Selector 2] 选中会话行   ├────────────────────────────────────────────┤
│      (#f8f8f8 → #ededed)     │ [Selector 1] 主工作区画布卡片 (.wSkVaW_body) │
│                              │  (柔白瓷渐变: #efefef → #e5e5e5)            │
│                              │   ├─ 工作区/模式选择胶囊                     │
│                              │   │   (微光纯白: #ffffff → #f4f4f4)         │
│                              │   └─ 底部输入控制台与 '+' 按钮               │
│                              │       (纯净白瓷: #ffffff → #f5f5f5)         │
└──────────────────────────────┴────────────────────────────────────────────┘
```

- **状态与样式同步机制**：
  - 当 Preset 1 处于浅色模式（`data-dsh-preset1-mode="light"`）时，CSS 变量令牌与组件级样式同步切换至上述三阶白瓷明度参数。
  - 滑块拖拽或点击切换深浅模式时，所有提亮组件保持 `0.52s cubic-bezier(0.22, 1, 0.36, 1)` 同步过渡动画，不产生色彩断层。
